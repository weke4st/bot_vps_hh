# HH Auto-Apply Bot 🤖

Production-ready сервис для интеллектуального и безопасного авто-отклика на вакансии [hh.ru](https://hh.ru).

Бот полностью автоматизирует процесс поиска работы: находит релевантные вакансии, генерирует персонализированные сопроводительные письма с помощью нейросетей (**GigaChat / DeepSeek**), автоматически отвечает на тесты работодателей, решает капчи через компьютерное зрение (**GigaChat-Pro**), имитирует поведение живого пользователя и предоставляет современный веб-интерфейс на **React + FastAPI** для мониторинга и управления.

---

## 🌟 Ключевые возможности

* **Антидетект-автоматизация**:
  * Эмуляция мобильного устройства (Google Pixel 7 на Android 14) через [Patchright](https://github.com/kaliiiiiiiiii/patchright).
  * Поведенческая мимикрия: движение курсора по кривым Безье, микро-дрожание, опечатки и их исправление, естественный скроллинг страницы.
  * Безопасные рандомизированные задержки между откликами (15–30 сек).
* **Умные сопроводительные письма**:
  * Персонализированное составление письма под требования каждой вакансии на базе вашего резюме с помощью **GigaChat API**.
  * Резервная поддержка **DeepSeek API**.
* **Автоматическое прохождение тестов работодателей**:
  * Выбор вариантов ответов (radio/checkbox) с помощью LLM.
  * Интеллектуальное распознавание зарплатных вопросов в анкетах с автоматической подстановкой желаемой зарплаты.
* **Решение CAPTCHA**:
  * Автоматическое распознавание капчи hh.ru через мультимодальное зрение GigaChat-Pro (до 3 попыток) без сторонних платных сервисов.
  * Поддержка локального OCR-сервера (PaddleOCR-VL).
* **Веб-интерфейс (SPA React + TailwindCSS + Recharts)**:
  * Запуск и остановка бота в один клик.
  * Живой стриминг логов в реальном времени по WebSocket.
  * Наглядная статистика: отклики за сегодня, за неделю, соотношение успешных и ручных откликов.
  * Интерактивная таблица всех вакансий с прямыми ссылками и статусами.
  * Управление текстом резюме, поисковым запросом, регионом и лимитами прямо из браузера.
* **Защита системы**:
  * Предотвращение засыпания Windows во время работы бота.
  * Строгий контроль часовых и суточных лимитов откликов.

## 🚀 Быстрый старт на Windows

Подробный иллюстрированный мануал для новичков доступен в файле **[MANUAL.md](MANUAL.md)**.

### 1. Автоматическая установка
Запустите файл **`setup.bat`**. Он автоматически создаст виртуальное окружение, установит все зависимости и браузер Chromium.

### 2. Настройка файла `.env`
Скопируйте `.env.example` в `.env` (если скрипт не сделал это сам) и вставьте ключ авторизации GigaChat:
```ini
GIGACHAT_AUTH_KEY=ваш_ключ_авторизации_gigachat
```
*(Бесплатный ключ берется на портале [developers.sber.ru](https://developers.sber.ru/)).*

### 3. Авторизация на hh.ru
Запустите **`login.bat`**:
* В открывшемся окне браузера войдите в свой аккаунт hh.ru.
* После успешного входа вернитесь в окно консоли и нажмите клавишу **Enter**.

### 4. Запуск бота
Запустите **`start_bot.bat`** и откройте панель управления в браузере:
👉 **[http://localhost:8000](http://localhost:8000)**

## 🐧 Запуск на Linux / Docker

### Ручная установка:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
patchright install chromium

cp .env.example .env
# Отредактируйте .env

# Ручной вход (требуется графический дисплей или VNC)
python login.py

# Запуск бота
python run_bot.py
```

### Запуск через Docker Compose:
```bash
docker-compose up -d --build
```
