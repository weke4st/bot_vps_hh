# 🚀 Развертывание облачного SaaS бота на VPS (Нидерланды / Ubuntu)

Данное руководство позволит вам за 5 минут развернуть бота в облаке на вашем сервере, чтобы вы и ваши друзья могли просто открывать сайт в браузере, регистрироваться, входить в свои аккаунты hh.ru по СМС и запускать авто-отклики.

---

## ⚠️ ВАЖНО: Прокси для сервера в Нидерландах!
Сервисы **HeadHunter (hh.ru)** и **Сбербанк GigaChat** блокируют запросы из европейских дата-центров (включая Нидерланды).
Чтобы бот работал стабильно и без блокировок, **обязательно используйте российский прокси (IPv4, HTTP или SOCKS5)**.
- Вы можете указать глобальный прокси в файле `.env`: `DEFAULT_PROXY=http://user:pass@ru-proxy-ip:port`
- Либо каждый пользователь может указать свой личный прокси прямо в веб-интерфейсе в разделе **"Настройки"** или в окне входа по СМС.
*(Стоимость обычного персонального прокси РФ — ~50–100 руб/мес на сайтах proxy6, proxyline и др.)*

---

## Шаг 1. Подключение к серверу и установка Docker

Подключитесь к вашему VPS по SSH:
```bash
ssh root@IP_ВАШЕГО_СЕРВЕРА
```

Установите Docker и Docker Compose (одной официальной командой):
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl
curl -fsSL https://get.docker.com -o get-docker.sh && sudo sh get-docker.sh
```

---

## Шаг 2. Клонирование репозитория

Склонируйте проект с GitHub:
```bash
git clone https://github.com/weke4st/new_bot.git
cd new_bot
```

---

## Шаг 3. Настройка конфигурации (`.env`)

Создайте рабочий файл `.env` из примера:
```bash
cp .env.example .env
nano .env
```

Отредактируйте параметры:
1. `JWT_SECRET`: вставьте любую случайную строку (например, сгенерируйте командой `openssl rand -hex 32`).
2. `DEFAULT_PROXY`: укажите ваш российский прокси, например:
   ```env
   DEFAULT_PROXY=http://login:password@185.123.45.67:8000
   ```
*(Сохраните файл комбинацией `Ctrl + O`, затем `Enter`, и выйдите через `Ctrl + X`).*

---

## Шаг 4. Сборка и запуск контейнера

Запустите контейнер в фоновом режиме:
```bash
docker compose up --build -d
```

Docker сам:
1. Скомпилирует React frontend.
2. Соберет Python бэкенд с Chromium и Patchright.
3. Запустит единый сервис на порту `8000`.

Проверить статус и логи:
```bash
docker compose logs -f
```

---

## Шаг 5. Как пользоваться (вам и вашим друзьям)

1. Откройте в браузере:
   ```
   http://IP_ВАШЕГО_СЕРВЕРА:8000
   ```
2. **Регистрация**:
   - При первом открытии появится окно входа/регистрации.
   - Нажмите вкладку **"Регистрация"**, введите имя, email и пароль.
3. **Подключение HeadHunter**:
   - В правом верхнем углу нажмите кнопку **"Подключить HH"**.
   - Введите ваш номер телефона (например, `+79991234567`).
   - Получите код по СМС и введите его в появившемся окне.
   - Бот авторизуется, сохранит сессию и предложит выбрать резюме для откликов.
4. **Настройки**:
   - Перейдите во вкладку **"Настройки"**.
   - Вставьте ваш персональный ключ **GigaChat API Key** (Base64 токен с developers.sber.ru).
   - Задайте поисковый запрос (например, `DevOps` или `Python разработчик`) и желаемую зарплату.
5. **Запуск**:
   - Нажмите зеленую кнопку **"Запустить"** в шапке сайта.
   - Бот начнет цикл поиска вакансий, генерации сопроводительных писем через нейросеть и отправки откликов!

## Полезные команды на сервере

- **Остановить бота:**
  ```bash
  docker compose down
  ```
- **Перезапустить бота:**
  ```bash
  docker compose restart
  ```
- **Обновить проект до последней версии:**
  ```bash
  git pull origin main
  docker compose up --build -d
  ```
- **Посмотреть логи в реальном времени:**
  ```bash
  docker compose logs -f --tail=100
  ```
